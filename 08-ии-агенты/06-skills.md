# Скилы (Skills)

> Навыки для ИИ-агентов: инструкции и знания для выполнения типовых задач.

## Что такое скил

**Скил (skill)** — набор инструкций и ресурсов, который «загружается» агенту под конкретную задачу.

Аналогия: **гайд для нового сотрудника**. Когда задача подходит под скил — сотрудник открывает гайд и действует по нему.

## Скил vs Промпт

| | Промпт | Скил |
|---|--------|------|
| Содержимое | Текстовая инструкция | Инструкция + ресурсы (файлы, примеры, скрипты) |
| Когда | Всегда в контексте | Загружается по необходимости |
| Объём | Обычно короткий | Может быть большой |
| Пример | «ты аналитик» | «скил тестирования: методологии, команды, примеры» |

## Структура скила (в OpenCode)

```
.opencode/skills/
└── code-style/
    ├── SKILL.md          ← главный файл с инструкциями
    └── resources/        ← вложенные файлы (примеры, чеклисты)
        ├── checklist.md
        └── style-guide.md
```

## Пример SKILL.md

```markdown
# Code Style Skill

Проверка и применение стиля кодирования.
Используй при написании нового кода, ревью или рефакторинге.

## Правила стиля
- Именованные экспорты
- TypeScript строже, чем JavaScript
- SOLID и DRY принципы

## Процесс проверки
1. Прочитать код
2. Проверить по чеклисту (см. resources/checklist.md)
3. Внести правки
...
```

## Характеристики хорошего скила

| Характеристика | Описание |
|----------------|----------|
| **Одна ответственность** | Один скил — одна область (тестирование, безопасность...) |
| **Конкретный триггер** | Описание «когда применять» |
| **Полнота** | Все необходимые инструкции внутри |
| **Примеры** | Хорошие/плохие примеры |
| **Проверяемость** | Чеклисты, критерии |

## Типичные скилы

| Скил | Когда применяется |
|------|-------------------|
| **code-style** | Написание/ревью/рефакторинг кода |
| **testing** | Написание и запуск тестов |
| **documentation** | Создание README, API docs |
| **security** | Поиск уязвимостей, настройка auth |
| **performance** | Оптимизация, профилирование |

## Как агент выбирает скил

```
Агент получает задачу:
  "Проверь безопасность конфигурации"
    │
    ├── Смотрит описание доступных скилов
    │   (skill: security — «проверка безопасности кода и конфигурации»)
    │
    ├── Совпадение → загружает SKILL.md
    │
    └── Действует по инструкциям скила
```

## Преимущества скилов

✅ **Знания по требованию** — не раздувают постоянный контекст  
✅ **Стандартизация** — единый подход к задачам проекта  
✅ **Переиспользование** — скилы идут с проектом/репозиторием  
✅ **Накапливаемый опыт** — улучшайте скилы по мере работы  

## Скил vs Команда

| | Скил | Команда |
|---|------|---------|
| Триггер | Автоматически по задаче | Явно пользователем (/review) |
| Контекст | Инструкции + ресурсы | Шаблон промпта |
| Применение | По описанию | По вызову |
