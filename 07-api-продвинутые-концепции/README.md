## Темы модуля

1. [GraphQL](01-graphql.md) — язык запросов для API
2. [Идемпотентность](02-idempotency.md) — безопасность повторных запросов
3. [Кэширование API](03-api-caching.md) — ускорение ответов

## Связь тем

```
Идемпотентность ── защищает от ДУБЛЕЙ платёжей при повторных запросах
Кэширование ── ускоряет ответы, но мешает идемпотентности/свежести
Auth ── определяет, кто может вызывать API
GraphQL ── альтернатива REST с гибкой выборкой данных
```
