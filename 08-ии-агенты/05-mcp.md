# MCP (Model Context Protocol)

> Стандарт подключения внешних инструментов и данных к ИИ-агентам. Открыт Anthropic (2024).

## Какая проблема решает MCP

До MCP: **каждая интеграция — свой формат**.

```
LLM приложение A  ── свой SDK ──►  БД
LLM приложение A  ── свой SDK ──►  GitHub
LLM приложение B  ── свой SDK ──►  БД
...
```

Много «своих» интеграций = **хаос и дублирование**.

Аналогия: до USB у каждого устройства был свой разъём. **MCP = «USB-C для ИИ-агентов»**. Один стандарт — для всех.

## Что такое MCP

**Model Context Protocol** — открытый протокол, определяющий, как агент (MCP host) подключается к внешним сервисам (MCP servers) для получения **инструментов, ресурсов и промптов**.

```
┌────────────┐   MCP-протокол    ┌──────────────┐
│  MCP Host  │◄─────────────────►│  MCP Server  │
│  (агент/   │                   │  (предоставляет│
│   OpenCode)│                   │   тулы/данные)│
└────────────┘                   └──────┬───────┘
                                        │
                                   ┌────▼────┐
                                   │ Сервис  │
                                   │ (БД, API,│
                                   │  файлы)  │
                                   └─────────┘
```

## Основные компоненты MCP

| Компонент | Что делает |
|-----------|-----------|
| **Host** | ИИ-приложение (OpenCode, Claude Desktop, IDE) |
| **Client** | Часть host'а, которая общается с сервером |
| **Server** | Сервер, предоставляющий возможности |
| **Тулы (tools)** | Функции, которые агент может вызывать |
| **Ресурсы (resources)** | Данные/файлы, которые можно читать |
| **Промпты (prompts)** | Готовые шаблоны инструкций |

## Концепции MCP

### Tools (инструменты)
Выполняемые функции:

```
Название: list_orders
Описание: Получить список заказов
Вход:     status (optional)
Выход:    массив заказов
```

### Resources (ресурсы)
Данные, которые можно прочитать (файлы, записи БД, документы):

```
URI:      db://orders/42
MIME:     application/json
Content:  { id: 42, total: 1500, ... }
```

### Prompts (промпты)
Готовые шаблоны для типовых задач.

## Пример подключения MCP

В `opencode.json`:

```json
{
  "mcp": {
    "github": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "..." }
    },
    "postgres": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-postgres"],
      "env": { "DATABASE_URL": "postgres://..." }
    }
  }
}
```

Теперь агент может:
- читать issues GitHub через тулл GitHub
- выполнять SQL-запросы к Postgres через тул Postgres

## Архитектурные варианты MCP

| Вариант | Тип | Когда |
|---------|-----|-------|
| **Локальный** | Процесс (npx, node, docker) | Разработка, локальные сервисы |
| **Удалённый** | HTTP(s)-сервер | Общие сервисы, SaaS |
| **Стандарт** | Streamable HTTP | Современная спецификация |

## Плюсы MCP

✅ **Стандарт** — одна интеграция работает во всех host'ах  
✅ **Расширяемость** — подключай любые сервисы  
✅ **Переиспользуемость** — один сервер, много host'ов  
✅ **Безопасность** — токены хранятся в env/local  
✅ **Открытость** — большой экосистемой серверов  

## Ограничения/замечания

⚠️ MCP — это механизм доступа, **не заменяет** кастомную логику  
⚠️ Нужно правильно настраивать права (не все тулы безопасны)  
⚠️ Удалённые серверы — отдельный уровень доверия
