## Какую диаграмму выбрать — быстро

```
Что нужно показать?
│
├── Модель данных (таблицы, связи)      → ERD
├── Бизнес-процесс (шаги, решения)      → BPMN 2.0
├── Взаимодействие сервисов по времени  → Sequence
├── Классы и их связи в коде            → Class diagram
├── Обзор системы целиком               → UML (контекст/компоненты)
└── Хранилище и его окружение           → Deployment diagram
```

## Инструменты для рисования

| Инструмент | Тип | Примечание |
|-----------|-----|-----------|
| **draw.io / diagrams.net** | Бесплатно, онлайн/офлайн | Универсальный, экспорт PNG/SVG |
| **Lucidchart** | Платный, онлайн | Командная работа |
| **PlantUML** | Код → диаграмма | Текстовая нотация, версионируется в git |
| **Mermaid** | Код → диаграмма | Встроен в Markdown/GitHub/Bitbucket |
| **Miro** | Доска | Мозговой штурм, командные воркшопы |
| **Enterprise Architect** | Профессиональный | Полный инструмент моделирования |
