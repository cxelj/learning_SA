## Ключевой вопрос модуля

**Кто управляет бизнес-процессом, который затрагивает несколько сервисов?**

| Подход | Кто управляет | Связность | Пример |
|--------|---------------|-----------|--------|
| Оркестрация | Центральный оркестратор | Слабая (все знают только оркестратора) | Orchestrator вызывает сервисы по очереди |
| Хореография | Никто / каждый сервис сам | Сильная (сервисы общаются событиями) | Сервис А публикует событие, сервис Б реагирует |
