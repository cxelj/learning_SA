# LLM модели (базовый обзор)

> Large Language Models — большие языковые модели. Базовые знания для понимания агентов.

## Что такое LLM

**LLM (Large Language Model)** — нейросеть, обученная на огромном объёме текста. Предсказывает следующее слово (токен), благодаря чему умеет генерировать связный текст, отвечать, писать код.

Типичный масштаб: **миллиарды параметров**, обучение на **терабайтах текста**.

## Ключевые понятия

| Понятие | Что значит |
|---------|-----------|
| **Параметры** | Числа в сети, определяющие «знания» (хранят веса) |
| **Токен** | Единица текста (слово/часть слова). Ограничение контекста в токенах |
| **Контекст** | Что модель «видит»: ввод (промпт) + ответ |
| **Контекстное окно** | Максимальный размер ввода (например 128K токенов) |
| **Температура** | Случайность ответа: 0 = строго, высокая = креативно |
| **Квантование** | Сжатие модели (меньше точность, но быстрее/меньше) |
| **Fine-tuning** | Дообучение модели на своих данных под свою задачу |
| **RAG** | Retrieval-Augmented Generation: поиск по данным + генерация |

## Как это работает (упрощённо)

```
1. Токенизация: "Привет мир" → [При, вет, мир]
2. Прогон через сеть: предсказание следующего токена за токеном
3. Выбор: "мир" → вероятности → выбор лучшего (с учётом температуры)
```

Модель **не «знает» в человеческом смысле** — она статистически генерирует наиболее вероятный текст.

## Галлюцинации

**Галлюцинация** — генерация уверенной, но ложной информации.

| Причина | Профилактика |
|---------|--------------|
| Модель придумывает «чтобы звучало правдоподобно» | RAG (поиск в данных) |
| Нет доступа к фактам | Проверка фактов, верификация |
| Устаревшие знания | Актуализация, доступ к инструментам |
| Двусмысленный промпт | Конкретика и контекст |

## Популярные семейства моделей (2026)

| Семейство | Разработчик | Особенность |
|-----------|-------------|-------------|
| **GPT** (GPT-4, GPT-5...) | OpenAI | Универсальные, сильный code |

| **Qwen** | Alibaba | Открытые, мультиязычные |
| **DeepSeek** | DeepSeek | Открытые, сильный code, дёшево |
| **Mistral** | Mistral AI | Открытые, европейские |

## Выбор модели

| Критерий | Что учитывать |
|----------|---------------|
| **Задача** | Чат, код, анализ, ревью (разные модели сильны в разном) |
| **Качество** | Бенчмарки (SWE-bench для кода) |
| **Скорость** | Время ответа (латенция) |
| **Цена** | Стоимость за токены (вход/выход) |
| **Контекст** | Хватает ли окна (документы, большой код) |
| **Приватность** | Локальная vs облачная (утечка данных) |

## Токены и стоимость

Провайдеры тарифицируют **токены**:

```
$ API: 0.003$ / 1K входных токенов, 0.015$ / 1K выходных
```

Прикидка: 1 токен ≈ 3-4 символа английского, ~2 символа русского.

Важно: **выходные токены дороже** входных.

## Мультимодальность

| Можно | Пример |
|-------|--------|
| Текст → Текст | генерация |
| Изображение → Текст | анализ картинок |
| Текст → Изображение | генерация картинок (не все LLM) |
| Аудио/видео → Текст | расшифровка (в новых моделях) |

## LLM и агенты

Модель — **мозг агента**. Но сам по себе LLM:
- Не умеет трогать файлы/команды/API
- Не знает о вашем проекте
- Не помнит между сессиями

**Превращение в агента** = LLM + инструменты + контекст + промпт + цикл выполнения.

```
LLM (мозг) + тулы (руки) + память/контекст = АГЕНТ
```

## Практические советы

1. Для кода и точных задач — модели с сильным code-скиллом (Claude, GPT)
2. Для анализа больших документов — нужен большой контекст
3. Для приватных данных — локальные модели (Llama, Qwen)
4. Проверяйте ответы про факты и API — галлюцинации возможны
5. Температура: для кода/фактов ниже (0-0.3), для креатива выше
