# Модуль 1: Коммуникации и протоколы

> Основы взаимодействия систем между собой.

## Темы модуля

1. [Kafka](01-kafka.md) — что такое очередь сообщений, топики, партиции
2. [API](02-api-basics.md) — что такое API, виды
3. [HTTP методы](03-http-methods.md) — GET, POST, PUT, PATCH, DELETE и др.

## Для чего это системному аналитику

- Понимать, **как системы общаются** между собой
- Уметь **проектировать API** и описывать его в требованиях
- Понимать **режимы взаимодействия** (запрос/ответ, событие, стриминг)
- Знать, когда применять **очереди сообщений** (Kafka) в архитектуре

## Ключевые термины модуля

| Термин | Определение |
|--------|-------------|
| API | Контракт взаимодействия между системами |
| HTTP | Протокол передачи данных (запрос/ответ) |
| Kafka | Распределённая платформа стриминга событий |
| Топик | Категория сообщений в Kafka |
| Партиция | Сегмент топика для параллельной обработки |

## Порядок изучения

1. Сначала HTTP методы — база всех веб-взаимодействий
2. Затем API — как контракты строятся на HTTP
3. Затем Kafka — асинхронная коммуникация
