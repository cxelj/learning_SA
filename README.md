## Как пользоваться репозиторием

1. Проходите модули **по порядку** — темы связаны между собой.
2. В каждом модуле есть `README.md` — обзор модуля, и файлы по темам.
3. В конце каждой темы есть **«Вопросы для самопроверки»** — попробуйте ответить без подглядок.
4. Создайте отдельный файл `notes.md` в корне — записывайте туда свои конспекты.

## Практические задания

Для закрепления материала (выполнять после прохождения модулей):

1. **Спроектируйте микросервисную систему** (например, интернет-магазин):
   - выделите сервисы, нарисуйте диаграмму
   - опишите взаимодействие (хореография/оркестрация)
   - выберите типы БД под разные сервисы
2. **Спроектируйте REST API** для одного сервиса:
   - определите ресурсы и HTTP методы
   - добавьте idempotency-ключи
   - опишите схему аутентификации
3. **Нарисуйте диаграммы** для своей системы:
   - ERD для модели данных
   - Sequence для одного бизнес-сценария
   - BPMN для процесса оформления заказа
4. **Настройте Kafka** локально (docker) и передайте сообщение между двумя приложениями.
