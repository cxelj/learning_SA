## Быстрая карта

```
LLM (модель) — "мозг": генерирует текст
    │  + инструменты (tools): чтение файлов, запуск команд, вызов API
    │  = ИИ-АГЕНТ — автономно решает задачи
    │
    ├── Управляется ПРОМПТОМ (системный промпт)
    ├── Расширяется СКИЛАМИ (навыки)
    ├── Общается с внешними сервисами через MCP
    └── Orchestration: агенты организуются в процесс (Harness Engineering)
```
