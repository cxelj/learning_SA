# OpenCode

> ОpenCode — агентный CLI-инструмент для разработки: ИИ-агенты работают прямо в репозитории.

## Что такое OpenCode

**OpenCode** — терминальный (CLI) инструмент разработки с ИИ-агентами. Агенты могут:
- читать и анализировать код проекта
- искать файлы и функции
- редактировать файлы
- запускать команды (тесты, сборка)
- выполнять многошаговые задачи автономно

Это «**Claude Code для любого LLM**» — агентная разработка в терминале.

## Ключевые концепции OpenCode

| Концепция | Описание |
|-----------|----------|
| **Агенты** | Роли с системными промптами (build, explore, plan, reviewer...) |
| **Саб-агенты** | Дочерние агенты для конкретных задач (исследование, ревью) |
| **Скилы** | Навыки: инструкции для выполнения типовых задач |
| **Команды** | Пользовательские команды (/review, /test, /plan) |
| **MCP-серверы** | Подключение внешних инструментов |
| **Модели** | Любой LLM: Anthropic, OpenAI, локальные |
| **Permissions** | Права на действия (что агенту разрешено) |

## Структура конфигурации

```
.opencode/                    ← директория проекта
├── agents/                   ← определения агентов
│   ├── build.md              ← агент для генерации кода
│   ├── explorer.md           ← агент для поиска
│   └── ...
├── skills/                   ← скилы (навыки)
│   ├── code-style/
│   ├── testing/
│   └── ...
├── commands/                 ← команды
│   ├── review.md
│   ├── test.md
│   └── ...
└── ...

opencode.json                 ← глобальная конфигурация
AGENTS.md                     ← инструкции проекта для агентов
```

## Агенты в OpenCode (пример проекта)

| Агент | Роль | Что делает |
|-------|------|-----------|
| **build** | primary | Генерирует и редактирует код |
| **explore** | subagent | Ищет и анализирует кодовую базу |
| **plan** | subagent | Декомпозирует задачи, проектирует |
| **reviewer** | subagent | Код-ревью |
| **tester** | subagent | Пишет и запускает тесты |

## Пример агента (файл .opencode/agents/build.md)

```markdown
---
description: генерация/редактирование кода
mode: primary
model: anthropic/claude-sonnet-4-6
tools:
  write: true
  edit: true
  bash: true
---
```

## Пример AGENTS.md

**AGENTS.md** — файл в корне репозитория, который агенты читают перед работой. Содержит правила проекта.

```markdown
# AGENTS.md

## Общее
- Все агенты — системные аналитики.
- Модель по умолчанию: anthropic/claude-sonnet-4-6

## Правила
- Не коммитить секреты в репозиторий.
- Письменный код должен следовать стандартам проекта.
- После изменения конфигурации opencode — перезапустить opencode.
```

## Типичный рабочий цикл

```
1. Пользователь: "Добавь endpoint для создания заказа"
2. Explore-агент: исследует структуру проекта, находит похожие endpoints
3. Plan-агент: предлагает план (файлы, изменения)
4. Build-агент: пишет код (правки через инструменты)
5. Tester-агент: пишет/запускает тесты
6. Reviewer-агент: проверяет код, стиль, ошибки
7. Пользователь: принимает/правит
```

## Плюсы OpenCode
